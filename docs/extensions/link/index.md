# iCal4j Extensions - Link

In iCal4j extensions we provide implementations of `LINK` types proposed in
[Semantic Calendaring](https://www.semcal.org/linking).

## Link Types

| Type | Description |
|------|-------------|
| Alternate | An alternate representation of the current object (e.g. in a different format or language) |
| Author | The author of the current object |
| Bookmark | A permanent link to the current object |
| Copyright | Copyright information for the current object |
| Edit | A resource where the current object may be edited |
| External | A resource external to the current object's origin |
| Help | Help or documentation for the current object |
| Hub | A Websub hub for subscribing to updates of the current object |
| Icon | An icon representing the current object |
| License | The license applying to the current object |
| Next | The next object in a sequence |
| Prev | The previous object in a sequence |
| Related | A resource related to the current object |
| Replies | A collection of responses to the current object |
| Self | The canonical location of the current object |
| Status | A resource describing the status of the current object |
| Webmention | A Webmention endpoint for the current object |
